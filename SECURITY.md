# Security Policy

## Supported Version

The latest stable 1.x release is supported.

## Reporting

Please do not publish exploitable vulnerabilities as ordinary public issues.

A useful report includes the affected component, reproduction steps, expected and actual behaviour, browser/platform and potential impact.

Relevant concerns include cross-site scripting, unsafe HTML handling, service-worker vulnerabilities, compromised dependencies, malicious URL handling, unintended data exposure and deployment configuration problems.

Bible Illuminated is primarily a client-side static application and does not require a user account.
